# Claude Code 固有のルール

## ユーザーに判断を求めるとき

判断を仰ぐときは必ず `AskUserQuestion` を使う。確認だけの短い問いも例外にしない。「進めてよろしいですか」と書きかけたら、それは `AskUserQuestion` の呼び出しである。

テキストを書いてすぐ `AskUserQuestion` を呼ぶと、そのテキストがユーザーに見えないことがある。質問の画面がそのテキストを隠す、ターミナル・デスクトップアプリ・VS Code の既知の不具合で（anthropics/claude-code#102864、#103084、#80576）、ユーザーは説明・表・URL を見ないまま答えを迫られる。判断に要るもの（説明・比較・URL・下書き・差分）は、次のどちらかで見せる。

- 短いものは質問の中に入れる。`question` と各選択肢の `description` に要点と URL を書き、全文を見比べるもの（下書き・差分）は単一選択の質問の `preview` に入れる。
- 長いものは、説明をテキストで書いたあと、同じ内容をスクラッチパッドのディレクトリに Markdown のファイルとして書き出し、それから `AskUserQuestion` を呼ぶ。`question` にはそのファイルのパスを書く。テキストのすぐ後に `AskUserQuestion` を呼ぶと、テキストと質問が 1 回の出力にまとまってテキストが隠れるが、書き出しを挟むと分かれる。隠れたときも、ユーザーはファイルを開いて読める。ユーザーに返事を打ってもらう手順は挟まない。

質問が拒否されたら、同じ形で聞き直さず、説明が見えていなかった可能性を先に疑い、上の手順で説明を書き出してから質問する。

## ツール

- 画面に影響する変更をしたとき、またはブラウザでの確認を頼まれたときは、`agent-browser` で実際の表示を確かめる。
- 「DeepWiki を使って」と言われたら DeepWiki の MCP を使う。MCP が使えなければ、有効にするようユーザーに伝える。
